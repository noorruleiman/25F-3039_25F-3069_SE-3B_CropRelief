# CropRelief — Flood And Crop Damage Reporting System

## Project Description
**CropRelief** is a 3-tier client-side web application built for flood-affected farmers and agricultural relief officials in Pakistan. It digitizes post-flood crop damage reporting and compensation approval through offline-first draft queuing, client-side photo compression (`< 500 KB`), GPS tagging, automated priority scoring (`Damage % × Flood Zone Factor`), duplicate claim prevention, role-based verification workflows, one-time rejection appeals, simulated SMS status alerts, and a bilingual English/Urdu interface.

## How to Run Locally
1. Clone or download this repository to your computer.
2. Open `index.html` directly in any modern web browser no backend server, database setup, or build step is required.
3. Click **Register** to create a new farmer account with CNIC and Khasra land details, or log in using any of the pre-seeded demo accounts below.
